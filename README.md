One funny single-line sport the Olympics turned down, written for the
[make.fun](https://make.fun/bounty/u-motasimfuad-rejected-olympic-sports-9d83e7da)
bounty "Rejected Olympic Sports".

## Entry

> Synchronised Queueing: four athletes, one post office, and a single clerk who went on break in 2019.

## How it works

`main.ts` writes the single line to `/output/entry.txt` (1–200 characters,
not only whitespace), as the bounty gate requires.

Run it with Node 22:

```sh
~/workspace/tools/node22/bin/node --experimental-strip-types main.ts
```
